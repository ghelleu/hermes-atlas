# Hermes Atlas — version 2 (15 octobre 2026)

Atlas interactif de l'architecture agentique Hermes, support de cours.

## Pour regarder ou partager : un seul fichier

`hermes-atlas.html` contient tout : style, données et script. Double-clic pour l'ouvrir dans Chrome, sans connexion. C'est le fichier à envoyer par mail ou à déposer sur un Drive.

## Pour modifier : le dossier `site/`

- `site/index.html` : la même page, découpée en fichiers.
- `site/data.js` : tout le contenu (composants, flux, mesures, parcours en 12 étapes). Modifier ici, sans toucher au code.
- `site/styles.css` : couleurs et tailles, dans `:root`.
- `site/app.js` : rendu et interactions.
- `site/README.md` : mode d'emploi complet et correspondance entre chaque composant et sa section du document source.
- `site/CHECK.md` : vérifications faites.
- `site/architecture.md` : le document source.

Après une modification dans `site/`, c'est `site/index.html` qu'on ouvre. Le fichier autonome ne se met pas à jour tout seul.

## Captures

`captures/` : quatre PNG en 3840 × 2160 pour les slides (vue d'ensemble, fiche, parcours, monolithe).

## Raccourcis

Espace : parcours · ← → : étapes · / : recherche · 0 : recentrer · Échap : fermer.
